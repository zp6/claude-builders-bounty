# CLAUDE.md Template: Next.js 15 + SQLite SaaS

Opinionated, production-ready CLAUDE.md for a SaaS project built with Next.js 15 App Router and SQLite.

## Usage

1. Copy `CLAUDE.md` to your project root
2. Customize the stack versions to match your project
3. Claude Code will automatically read it for context

## What's Covered

- Stack & versions
- Folder structure conventions
- Database/SQL migration rules
- Component patterns (Server vs Client)
- Naming conventions
- What we don't do (and why)
- Dev commands
- Anti-patterns to avoid
- Stripe integration guidelines

## Philosophy

Every rule has a reason. This isn't generic advice — it's specific decisions for this stack combination.
